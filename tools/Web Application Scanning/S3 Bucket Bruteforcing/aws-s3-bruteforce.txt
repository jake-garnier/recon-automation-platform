aws-s3-bruteforce
=================

URL: https://github.com/Ucnt/aws-s3-data-finder/

AWS S3 bucket brute-force tool. Discovers publicly accessible S3 buckets by testing common naming conventions.

Usage: Discover open S3 buckets related to a target.
Input: Company/target name or wordlist.
Output: Discovered accessible S3 buckets.
