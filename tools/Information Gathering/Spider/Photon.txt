Photon
======

URL: https://github.com/s0md3v/Photon

Incredibly fast web crawler designed for OSINT. Extracts URLs, emails, social media accounts, files, secret keys, and JavaScript files.

Usage: OSINT-focused web crawling.
Input: Target URL.
Output: Extracted URLs, emails, accounts, files, secrets.

Example:
  python3 photon.py -u https://example.com -o output/
